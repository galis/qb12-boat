### 6.2 小实验（`#p6-toy-svg`，示意）
8 个标签页，每页一个参数（滑块 + 在图里拖带“拖我”的东西）。越过规则时右边列表出现 KiCad 的违规名（中文界面原名）和严重级别（取自 QB12.kicad_pro 的 rule_severities）：
1 间距（下面那根线上下拖）→ 间距违规；空隙为 0 再加“短路两个网络的项目”。规则 = Default 网络类 0.18 mm（底线 0.15）。
2 线宽（上下拖）→ 走线宽度（< 0.15）；0.15–0.2 之间显示“提示：不算违规”（网络类线宽只是默认值，facts §6.2）。
3 孔环（孔 0.3 不变，拖外径）→ 孔环宽度（< 0.1）。
4 孔到孔（两个 GND 过孔，拖右边那个）→ 钻孔太靠近其他孔（孔边距 < 0.25）。
5 板边（拖线）→ 电路板边缘间距违规（< 0.3）；浅色带 = 铣刀误差 ±0.2 mm。
6 没连上（拖走线终点）→ 项目之间的连接缺失（错误，“未连接项目”页）+ 走线末端悬空（警告），画飞线。
7 外框重叠（拖 R2）→ 元件外框重叠；再近 → 间距违规（焊盘间距 < 0.18）。
8 丝印（上下拖位号 R5）→ 丝印间距（压线框；8.0.9 叫“丝印重叠”）/ 被阻焊层截断的丝印（压焊盘，落在开窗里的部分画成虚线）。
每页底部一句 QB12 在这一类的真实情况。

### 6.3 报告（`#p6-rep-*`）
上面 5 个读数：错误 0、警告 143、未连接 0、原理图一致性“没查”、排除 0；下面一行仿 KiCad 选项卡：违规 (143) · 未连接项目 (0) · 原理图一致性 (不运行) · 忽略的测试 (7)。
左：4 类（KiCad 界面名 + board.json 的白话名 + 条数）+ 每类一个严重级别下拉框（错误 / 警告 / 忽略），下面是该类每一条（KiCad 10 报告里本来就是中文：“C3 的参考字段 ↔ C3 的 线段, 位于 F.Silkscreen”，附近元件，坐标）。
点一条 → 查看器（层叠视图，按类型换层：丝印类 = 铜 + 丝印，阻焊截断 = 铜 + 阻焊 + 丝印，库 = 铜 + 占位框 + 位号并框出该元件，板边 = 丝印 + 占位框 + 板框）放大到该点（约 15 × 10 mm），本类所有条目小黄圈、选中那条大圈 + 十字；背面的条目（底层丝印）自动翻到底面。卡片：这一类是什么、QB12 为什么有、要紧吗；选中那条可以“排除此违规”，总数跟着变。改严重级别：例如库那类改成“错误”→ 51 错误 / 92 警告；任何一类改成“忽略”→ 列表清空、“忽略的测试”+1。
手机（≤ 860 px）：查看器排在最上面并 sticky 在视口顶上，列表在下面滚。
“被板边截断的丝印”4 条：报告里第一个坐标是板框线的起点 (0,36)/(54,38)，课里改用第二个坐标（伸出板边的那段丝印：SW1 (−1.13, 25.03)、(0.47, 23.75)，J1 (22.03, 38.69)、(30.97, 38.69)，来自 `../../hardware/pcb/out/QB12_drc.json`）。

## 外部事实（facts.md）
- 线宽 / 线距 0.10 mm、线宽公差 ±20%、外形锣边 ±0.2 mm、过孔最小 0.15 / 0.25、外径比孔大 ≥0.1（推荐 0.15）、孔位公差 ±0.075 mm、孔到孔 过孔 0.2 / 插件孔 0.45、铜到板边 0.2、丝印字高 ≥1.0 / 线宽 ≥0.15、嘉立创“高精字符”0.8 / 0.1、钻孔 0.15 起（嘉立创“非常规”，推荐 ≥0.2）、加价过孔规则：§1.1 [S01][S02][S03]。
- 经济型贴片分板约 0.2 mm 公差、建议离板边 >0.3：§4.1 [S07]。
- 丝印和 CPL 矛盾时默认按丝印贴：§4.5 [S07]。
- 字符到焊盘不够会被掏掉（课里说“开窗里的丝印会被去掉”）：§1.1 [S02][S03]。
- KiCad 默认值（网络类 0.2 / 0.2 / 0.6 / 0.3、铜到板边 0.5、最小钻孔孔径 0.3、孔到孔 0.25、字高 1.0、丝印线宽 0.1）：§6.4 [S34]；10.0.6 和 8 一样（facts_kicad10.md #108–#110）。
- 网络类线宽只是默认值、任何规则不能低于约束页：§6.2 [S30]。
- 菜单：检查 → 设计规则检查（无快捷键）、视图 → 3D 查看器 Alt+3、文件 → 电路板配置...：§6.1 [S33]；其余界面文字（违规严重级别、排除此违规、忽略所有 '…' 违规、在执行 DRC 之前重新填充所有覆铜区、齿轮菜单里的 为每条走线报告全部错误、检查 PCB 和原理图是否一致、违规 / 未连接项目 / 原理图一致性 / 忽略的测试、管理封装库...、从库中更新封装...、文本与图形 → 默认、封装属性 → 3D 模型、约束页的 最小过孔外径 / 最小钻孔孔径、各违规类型名，丝印间距 / 封装与来源库中的封装存在不一致）2026-10-20 查自本机 10.0.6 的 zh_CN kicad.mo 和 `../facts_kicad10.md`（原来查的是 8.0.9）。
- ESP32 天线：最好伸出底板、馈点靠近板边，外壳里四周 ≥15 mm 净空：§8.3 [S46]。
