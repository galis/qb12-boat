6

检查：DRC 与 3D

学完能说清：DRC 拿什么规则查、查些什么；QB12 的检查报告里每一类警告是什么意思、哪些要管；哪些事 DRC 查不出来，要打开 3D 自己看；下单前最后一遍对哪些项。

6.1规则从哪来：工厂能做多细，规则就别比它细

DRC（Design Rule Check，设计规则检查）是 KiCad 自带的一项检查：把板上每一根线、每一个焊盘、每一个孔两两拿出来量，看有没有违反你定的规则。它只认规则，不认工厂。规则写松了，DRC 照样说“没问题”，到工厂才出事。

所以规则要从工厂的制造能力来，再留一点余量。为什么要留？嘉立创的线宽公差是 ±20%，0.1 mm 的线做出来可能只有 0.08 mm；板子外形是铣刀铣出来的，位置有 ±0.2 mm 的误差。规则比工厂极限宽一些，这些误差就吃得下。

工厂极限（JLC / 嘉立创） QB12 的规则 QB12 板上实际最紧 KiCad 默认

横轴是“工厂极限的几倍”：竖线处 = 1 倍，正好卡在工厂能做的极限上；越往右越保险。点一行看具体数字和板上最紧的地方。

KICAD 里自己做打开 文件 → 电路板配置...，左边选 设计规则 → 约束。照工厂能力页填：最小间距、最小走线宽度、最小孔环宽度、最小过孔外径、铜箔到板边间距、最小钻孔孔径、孔到孔的间距、最小文本高度……这页是“底线”，网络类（第 4 课）和手动改的尺寸都不能低于它。KiCad 新建工程的默认值大多比工厂极限宽，但丝印线条默认只有 0.1 mm，工厂要 ≥0.15 mm，在 文本与图形 → 默认 里改成 0.15。

6.2DRC 在找什么：自己拖一拖

DRC 查的东西可以分成三类：铜和铜（线宽、间距、有没有短路）、孔（孔环、孔和孔、孔离板边）、连没连上（同一个网络的焊盘是不是都用铜连通了）。另外还查元件的占位框有没有叠在一起、丝印有没有压到焊盘上。

KICAD 里自己做在设计规则检查窗口的列表里右键一条，可以选 排除此违规（只放过这一条，KiCad 会记住，下次不再报），或者 忽略所有 '…' 违规（整类都不查了，慎用）。整类改级别在 文件 → 电路板配置... 的 设计规则 → 违规严重级别，每一类都能设成错误、警告或忽略。“在库中找不到封装”这一类，去 设置 → 管理封装库... 把工程自己的封装库登记上就好。注意别随手点 工具 → 从库中更新封装...：板上故意改过的封装会被换回库里的样子。

  


  
  

    
6.5DRC 不知道的事：打开 3D 看实物

    

      
DRC 只认铜、孔和丝印的平面形状。插座朝哪边开口、插头插不插得进去、天线外面是不是金属、元件有多高、电池线哪根是正极，它统统不知道。这些要靠 3D 视图：KiCad 用每个封装附带的 3D 模型，把装好元件的板子画出来，像拿着实物转着看。

    DRC 显示 0 个错误、0 处未连接，是不是就可以下单了？
