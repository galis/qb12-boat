板框与布局

学完能说清：QB12 为什么是 mm；板框是一条什么样的线、铜为什么要离它 mm； 个元件按什么顺序、什么道理摆到现在的位置；在 KiCad 里怎么画板框、摆元件。

3.1板子多大： 是怎么来的

板子越小，一张大料上能切出的板越多，越省钱；可太小了元件挤不下，线也没地方走。所以板子的大小不是先拍脑袋定的，是被两类东西“撑”出来的：必须贴着板边的（插座、USB 口、开关、天线），和必须塞进去的（最大的一块是 ESP32 模组）。

先说实话：build_board.py 里只有一行 BW, BH = 56.0, 38.0，没写为什么。下面三种看法是从元件的真实位置倒推出来的。

再看外面的门槛。板厂和贴片厂对尺寸都有要求，QB12 这个大小正好落在经济型贴片最省事的那一档里。不过实际下单走的是标准型，因为经济型不贴 ESP32 模组 U1（第 8 课 8.3）。点下面的按钮，图会按同一比例画出来。

KICAD 里自己做KiCad 里没有单独的“板子尺寸”设置：Edge.Cuts 层上画的外形就是板子，工厂按它切。常见做法是先画一个宽松的框，把接口、模组这些“定死”的元件摆上去，再把框收紧到刚好包住。怎么画见 3.2 和 3.5。

3.2板框：Edge.Cuts 层上一条闭合的线

Edge.Cuts（板框层，中文界面也叫“板框”）上只画一样东西：板子的外形。工厂的 CNC 锣机（铣床）沿着这条线把板子从大料上铣下来。所以它必须首尾相接、围成一圈：缺一个口，就分不清哪边是板子、哪边是废料。

QB12 的外形是 mm 的圆角矩形：4 段直线 + 4 段四分之一圆弧，圆角半径 mm，线宽 mm。圆角只是为了拿在手里不扎手、角上不容易磕坏（这是常见做法，脚本里没写理由）。

直线（seg）90° 圆弧（arc）①–⑧ 是脚本画的顺序

        
build_board.py 画板框的真实代码（节选）。seg 画一段直线，arc 画一段 90° 圆弧，都放在 Edge_Cuts 层、线宽  mm。

      

    


    

      
铜要离板边远一点。锣机铣出来的外形有公差：JLC 写的是普通锣边 ±0.2 mm。铜离边太近，铣刀就可能蹭到铜：露铜、毛刺，甚至把线切断。拖动下面的滑块，看铜离板边多远才放心。

3.3摆元件：从一堆到各就各位

    

      
元件刚从原理图导进 PCB 时堆成一堆，每个焊盘拉着细线连到它该连的焊盘，这些线叫飞线（ratsnest，“这里还没连，但应该连”）。摆放的目标很朴素：飞线越短、越少交叉，后面越好走线；同时满足每个元件自己的要求：接口要贴边，天线下面不能有铜，去耦电容要贴着芯片的电源脚。

      
顺序也有讲究：先摆位置被外面定死的（接口、开关、模组），再按电流和信号的路一组组往里填。点“一组组摆上去”，看 QB12 的  个元件按这个顺序落位，右边的卡片说明每一组为什么放在那。

    

    

      

        
        
        
        
      

      

      

        

          

          

        

        

          

          

          

          

          

        

      

      
飞线是示意：每个网络按当时的焊盘位置算一棵最小生成树（把所有焊盘连起来、总长最短的那组直线），和 KiCad 显示飞线的思路一样。没摆好的元件画淡一些，堆的样子也是示意。中间几步交叉数可能先变多：一部分元件还在堆里，连向它们的飞线会横穿整块板。

    

    

      

        
QB12 实际怎么摆的：没有拖鼠标。build_board.py 里有一张坐标表 PLACE，每个元件一行：中心点 x、y（mm，原点在板框左上角）和旋转角。脚本按网表把封装一个个放到这些坐标上，最后检查一遍：表里漏了谁，就打印“未摆放：”。

        
坐标表里的数都是 0.1 mm 的整数倍（只有 ），角度只有  几种。这和在 KiCad 里打开 0.1 mm 栅格、只按 90° 转是一样的效果：元件排得整齐，丝印也好对齐。

3.4自己挪一颗：元件外框、距离和“只贴一面”

    

      
每个封装外面都有一圈元件外框（courtyard，查看器里叫“占位框”）：元件本体再加一点余量。贴片机的吸嘴要落下去、焊锡要有地方润湿、返修时烙铁要伸得进去，这圈地方就是留给它们的。规则只有一条：两个元件外框不许重叠，重叠了 KiCad 的 DRC 会报“元件外框重叠”。

QB12 怎么查的：坐标表改完，先跑 check_place.py：它把每两个元件的外包框比一遍，重叠超过 0.15 mm 的打印“重叠”，超出  板框的打印“出板”。在最终的板子上跑，结果是右边这样：0 处重叠，出板的只有两个。

        
这两个是故意的：USB-C 插座 J1 的插口要伸到板外，插头才插得进去；拨动开关 SW1 的拨杆要伸出左边，手指才拨得到。脚本的框比查看器里的元件外框稍大（它把封装上所有图形都算进去了），用元件外框算，J1 伸出下边  mm，SW1 伸出左边  mm。

        
元件摆得密，位号丝印也难放：finalize.py 给每个位号找一个不压焊盘、不压别的元件的位置，“放不下就隐藏”。QB12 有  个位号因此没印出来：。

      

      

        

        
在交付的 out/QB12.kicad_pcb 上运行 check_place.py 的原样输出（坐标是板子本地 mm）。脚本要 import pcbnew，所以用 KiCad 自带的 Python 跑：$KPY 的路径写在 tools/kicad_env.sh 里。

      

    

    

      

        
为什么全放在顶面？QB12 的  个元件全在顶面，底面只有铺铜、过孔和几行丝印字。原因在贴片厂：JLC 的经济型贴片只能贴一面；标准型可以贴两面，但工程费、钢网费都分单面和双面两档，双面贵（具体金额以下单页为准）。两面贴还要多一张钢网、多过一次回流焊。QB12 实际走标准型（经济型不贴 ESP32 模组 U1，见第 8 课），但只贴顶面，所以仍然只用一面的钢网、过一次回流焊。

        
乐鑫给双层板的建议也一样：底层不放元件、少走线，留一整面地。QB12 导出坐标文件时也只导了顶面。点右边的按钮把板子翻过来看。

      

      

        

          
          
        

        

        

      

    

  


  
  

    
3.5KiCad 里自己做：导入、规则、画框、摆放

    
QB12 这一步是脚本做的（第 0 课说过）。你自己在 KiCad 10 里做，通常按下面四步走。点数字切换。

    

      

        
        
        
        
      

      

        
KICAD 里自己做
          原理图和 PCB 要在同一个工程里，并且从 KiCad 项目管理器打开。原理图画好、每个符号都填好封装以后，点 工具 → 从原理图更新 PCB...（F8，原理图编辑器和 PCB 编辑器里都有）。对话框里点 更新 PCB，新封装会挤成一堆跟着鼠标走，在板框外面的空地上点一下放下，再一个个挪进去。
          以后原理图改了，再按一次 F8：已经摆好的元件留在原地，只增删改变了的部分。
          QB12 没有 KiCad 原理图，所以在它的 PCB 编辑器里这一项是灰的。build_board.py 直接读 netlist.py，把封装放到坐标表的位置上，效果相当于“导入 + 摆好”一步完成。
        

        
      

      

        
KICAD 里自己做
          文件 → 电路板配置...，左边选 设计规则 → 约束。“铜箔到板边间距”填  mm：KiCad 新建工程默认是 0.5 mm，JLC 锣边最少要 0.2 mm。
          规则先设好再摆、再走线：后面布线和铺铜都按它让开板边，DRC 也按它检查。线宽、过孔这些也在同一页，第 4、5 课再讲。
        

        
      

      

        
KICAD 里自己做
          在右边 外观 面板的 层 里点中 Edge.Cuts（板框）。放置 → 绘制线条（Ctrl+Shift+L；Windows / Linux 菜单里显示成 Shift+Ctrl+L，mac 显示 ⇧⌘L）一段段点，回到起点就闭合了；直角的板也可以用 放置 → 绘制矩形 一次拉出来。
          要圆角：选中四条线，右键 形状修改 → 圆角线...，填半径（QB12 是  mm）。
          再用 放置 → 栅格原点 点在板框左上角，再到 设置 → 偏好设置... → PCB 编辑器 → 原点和轴 里把 显示原点 选成 栅格原点，屏幕上的坐标才从这个角开始算，和 QB12 的坐标表一样（只放栅格原点，挪的只是栅格）。交付的 QB12 文件里，finalize.py 最后把栅格原点挪到了左下角，和钻孔/定位原点放在一起（第 7 课）。QB12 的板框在 KiCad 文件里放在 (100, 100) mm 处（脚本里 OX, OY = 100.0），所以文件里 U1 的位置写的是 ()。
        

        
      

      

        
KICAD 里自己做
          鼠标指着元件按 M 移动（元件跟着鼠标走，点一下放下）；R 逆时针旋转、Shift+R 顺时针旋转；F 换面 / 翻转（翻到底面，QB12 用不到）；Shift+M 精确移动，直接输入要挪多少 mm。
          栅格：N / Shift+N 切换到下一个 / 上一个栅格，Alt+1 / Alt+2 切到两个快速栅格。粗摆用大栅格，细调用小栅格。
          按 Home（视图 → 自适应缩放；mac 上是 ⌘+0）随时回到看全板。边摆边看飞线：越摆越短、越少交叉就对了。摆完跑 检查 → 设计规则检查，看有没有“元件外框重叠”（第 6 课细讲）。
