# KiCad 截图清单（kicad_shots.md）

KiCad 10.0.6（Mac，装在 `~/Applications/KiCad`），简体中文界面，2026-10-20 拍摄。用一份单独的 `KICAD_CONFIG_HOME`（隔离配置），不碰用户自己的 KiCad 设置。主窗口固定为 1400×900（点），左上角放在屏幕 (60, 60)。用 `screencapture -l<窗口号>` 截窗口，得到 2× 视网膜图；对话框按它在窗口里的位置裁出来，再缩到 1×（点）像素。窗口操作用 computer-use 完成。

工程是 `outputs/QB12/QB12_KiCad工程.zip` 解压出来的工作副本。工作副本为了拍图改过几处：预设尺寸表填了数（交付的工程包这张表是空的）；绘制 / 钻孔 / 坐标文件对话框事先按 JLC 设置填好；“只看板框”“只看 B.Cu”两张是改工作副本 `.kicad_prl` 的 `visible_layers` / `visible_items` 做出来的。演示工程（R1 / D1 / J1，不是 QB12）用 `tools/kshot/demo_project.py` 生成（用 `.venv-kicad` 的 python 跑），从 KiCad 项目管理器打开原理图再操作：单独启动原理图编辑器时，“从原理图更新 PCB”是灰的。

Mac 版的菜单栏在屏幕顶上，不在窗口里，所以这批截图里都**看不到菜单栏**，各节的“打开方式”写的是菜单路径。对话框按钮是中文的 取消 (C) / 确定 (O)（8.0.9 Linux 版是英文 Cancel / OK）。有几张主窗口标题是“*QB12 — PCB 编辑器”，`*` 是未保存修改的标记，不用管。

WebP，最宽 1400 px，质量 80（`kicad_zones_unfilled` 用 65，为了压到 120 KB 以内）。

`tools/kshot/` 里的 `kshot.py` / `prepare.py` / `report.py` 是上一版（KiCad 8.0.9）用的 Linux + Xvfb 自动截图脚本，这次**没有用**，是在 Mac 上手动操作截的。

## 制作说明

* 拍法：Mac 上的 KiCad 10.0.6，隔离的 `KICAD_CONFIG_HOME`；主窗口 1400×900、位置 (60, 60)；`screencapture -x -o -l<窗口号>` 截 2× 图，对话框按屏幕坐标从主窗口截图里裁出来（相对主窗口原点 (60, 60)）；DRC 窗口是非模态窗口，要用它自己的窗口号单独截，不能从主窗口里裁；用 PIL LANCZOS 缩到 1×（`kicad_layers_panel` 是 1.5 倍）；computer-use 操作界面。拍摄用的小脚本 `shot.sh` / `crop.py` 只放在会话的临时目录里，没有进库。
* 工程：`outputs/QB12/QB12_KiCad工程.zip` 解压的工作副本。预设尺寸表、绘制 / 钻孔 / 坐标文件对话框的 JLC 设置都是在工作副本里事先填的，不是交付工程包的原样；“只看板框”“只看 B.Cu”改的是工作副本 `.kicad_prl` 的 visible_layers / visible_items。
* 演示工程：`tools/kshot/demo_project.py`（用 `.venv-kicad` 的 python 跑）生成，从 KiCad 项目管理器打开原理图（单独启动原理图编辑器时 从原理图更新 PCB 是灰的）。
* 输出：WebP，最宽 1400，质量 80；`kicad_zones_unfilled` 用 65，压到 120 KB 以内。
* `tools/kshot/` 下的 `kshot.py` / `prepare.py` / `report.py`（和 `tools/kshot/README.md` 里的步骤）是上一版 KiCad 8.0.9 在 Linux + Xvfb 里自动截图用的，这次没有用。
