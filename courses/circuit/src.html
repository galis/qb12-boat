先看全景：这块板在做什么

学完能说清：电从哪来、分成哪几路、信号从手柄怎么走到电机。

0.1先说两个最基本的概念

电压像水压

电压是两点之间的“压力差”，单位伏（V）。原理图里说某根线是 5V，意思是它比地（GND）高 5V。

电流像水流

电流是真正流过去的量，单位安（A）。ESP32 大约用 0.1 A，一个 130 电机起步能到 1 A 以上，所以电机那一路的线要粗。

电流要走一个圈

电流从电源正极出发，经过元件做功，再从 GND 回到电源负极。断开圈上任何一处，电流就停了。开关就是靠这一点工作的。

0.2整块板分三件事

管电：USB-C 进来 5V，一边给电池充电，一边给全板供电；没插 USB 时改由电池供电。原理图里的 A 区和 B 区。

动脑：ESP32-S3 通过蓝牙连上 Xbox 手柄，读到摇杆位置，算出左右两个电机各转多快。C 区。

出力：ESP32 的引脚只能给出几毫安的小信号，推不动电机。DRV8833 把这些信号“放大”成能推动电机的大电流。D 区。

原理图不是板子的照片。图上元件摆在哪里、线画多长，跟实际板子上的位置没有关系。它只回答一个问题：每个元件的每个脚，接到了哪根线上。

1.2先认符号

电阻位号 R · 单位 Ω限制电流、分压、上拉下拉。本板 18 个。
电容位号 C · 单位 F（µF、nF）像小水箱：存一点电，电流突然变大时先顶上。本板 15 个。
二极管位号 D · A 阳极 K 阴极单向阀：电流只能顺着三角形箭头方向走，从 A 到 K。
LED 发光二极管位号 LED也是二极管，电流从 A 流到 K 时发光。一定要串电阻限流。
按键 / 开关位号 SW按下时两端接通。SW2 是 BOOT、SW3 是 RESET。
芯片 / 模组位号 U · 方框加引脚框外的小数字是引脚号（实物上第几个脚），框里的字是引脚名（这个脚管什么）。

网络标号橙色 = 电源 · 青色 = 信号这张图最重要的记号，下一节专门讲。
叉号 ×NC · 不连接这个脚故意空着，不是漏画了。比如 USB-C 的 SBU 脚。
MOS 管 Q1、Q2 在这张图里画成小方框，三个脚写着 D G S（漏极、栅极、源极）。它的原理第 4 课细讲。

1.3网络标号：名字相同，就是连在一起

如果把所有导线都真的画出来，这张图会变成一团乱麻。所以画图的人给每根线起了名字，在要接的地方贴一个写着名字的小标签。名字一样的标签，就是同一根线，哪怕它们在图的两个角落。

下面这个例子里，左边是 USB-C 的 VBUS 脚，右边是充电芯片的 VCC 脚。图上看它们之间没有线，但两个都贴着 VBUS，所以实际上是连着的。黄色虚线就是那根“看不见的导线”。

整张图里一共有 11 个 VBUS 标签，全部是同一根线。

名字的写法也有讲究。名字开头带 n 或结尾带 _N 的，比如 nSLEEP、PWR_EN_N，意思是低电平有效：这根线拉到 0V 时功能才生效。STM32 的 NRST 也是这个意思，拉低才复位。

1.4位号、参数和引脚号

  1. 位号 R4：这颗电阻的名字。BOM 清单和板子丝印上都印它，找元件就靠它。
  2. 参数 1kΩ：阻值。电容这里写容量，芯片写型号。
  3. 上端网络 VBUS：R4 的一个脚接在 USB 的 5V 上。
  4. 下端网络 LED1_A：另一个脚接在红灯 LED1 的阳极。
  5. 合起来读：VBUS → R4 → 红灯 LED1。这一句就是这颗电阻在电路里的意义。

芯片的读法一样：比如 U4 框外写着 4，框里写着 VCC，标签是 VBUS，读作“U4 的第 4 脚是电源脚，接在 VBUS 上”。引脚号对应芯片实物，从数据手册里的引脚图查得到。

1.7自测三题

红灯 LED1 的两端分别接在哪两个网络上？它什么时候会亮？

阳极接 LED1_A，经过 R4 连到 VBUS；阴极接 CHRG，连到充电芯片 U4 的第 7 脚。充电时 U4 把 CHRG 拉到地，电流 VBUS → R4 → LED1 → U4 流过去，灯就亮了。

ESP32 的 IO4 最后接到了哪个芯片的哪个脚？

IO4 的标签是 AIN1。另一个 AIN1 标签在 D 区，接 U2（DRV8833）的第 16 脚 AIN1，也就是左电机的控制输入之一。

电源开关 SW1 拨到 ON 时，PWR_EN_N 是高电平还是低电平？

低电平。B 区里 SW1 的 ON 脚接地，拨到 ON 时公共脚 COM（网络 PWR_EN_N）就被接到地。名字结尾的 _N 也提示了：它是低电平有效，拉低等于“开”。具体为什么拉低就能开机，第 4 课讲 MOS 管时揭晓。

USB-C 接口：5V 是怎么进来的

学完能说清：USB-C 每个脚管什么、为什么必须有两颗 5.1kΩ、ESD 芯片怎么保护 ESP32。对应原理图 A 区左半边：J1、R1、R2、U5。

2.1接口里有两排脚，上下是镜像的

USB-C 能正着插也能反着插。做法是把接口里的脚排成上下两排：上排叫 A1–A12，下排叫 B1–B12，而且下排是倒着排的，B1 在 A12 正下方。插头翻个面，原来碰 A 排的触点就碰到 B 排。只要转 180° 后对上的两个位置功能一样（比如 A5 对 B5），正反插效果就一样。

我们用的 TYPE-C-31-M-12 是 16 脚版本，只有 USB 2.0 的脚。完整的 24 脚接口多出来的 8 个脚是高速线，给 USB 3 和视频输出用，这块板用不上。

插头方向

所以原理图里 J1 的引脚写成了组合：A4,A9,B4,B9 都是 VBUS，A6,B6 都是 D+，A7,B7 都是 D−。正插时插头碰到 A6、A7，反插时碰到 B6、B7，两组都接到同一根线，ESP32 就不用管你怎么插的。

CC 脚不一样：插头上只有一个 CC 触点，正插碰 A5（CC1），反插碰 B5（CC2）。两边都要接电阻，这就是下一节的 R1 和 R2。

2.2两颗 5.1kΩ：告诉充电器“我要电”

老式 USB-A 口插上就有 5V。USB-C 的规矩不同：C 对 C 的线两头长得一样，充电器不知道对面是手机、是另一个充电器，还是根本没插东西，所以默认不出电。

它的判断办法是看 CC 线的电压。充电器在 CC 上挂一个上拉电阻 Rp 到 5V；用电的一方在 CC 上挂一个 5.1kΩ 下拉电阻 Rd 到地。两颗电阻一分压，CC 电压就被拉到 0.4V 左右。充电器看到这个电压，就知道“对面接了个要电的设备”，这才打开 VBUS 的 5V。

板子上的 R1 充电器档位

算一下普通档：CC = 5V × 5.1 ÷ (56 + 5.1) ≈ 0.42V。普通档的充电器只要看到 CC 落在 0.2–1.6V 之间，就认定接了用电设备（1.5A、3A 档上拉更强，这个范围也跟着更高）。漏焊 R1 时，CC 被 Rp 一直拉在 5V，充电器以为没插东西。

Rp 的大小还顺便告诉用电方“我最多能给多少电流”：56kΩ 是普通 USB，22kΩ 是 1.5A，10kΩ 是 3A。QB12 不去读这个档位，只拿默认的 5V。快充那种 9V、12V 要另外的 PD 协议芯片去谈，这块板不需要。

常见的坑：网上很多 USB-C 小板用 A 转 C 的线能充电，换成 C 对 C 线就没反应，原因就是漏了这两颗电阻。A 转 C 的线里自带 56kΩ 上拉，A 口又是一直有电的，所以不挑设备。

2.3D+ / D−：数据线和静电保护

D+、D− 是一对差分线：两根线同时传一正一反的信号，接收端只看两根之差。外面的干扰会同时加到两根线上，一相减就抵消了，所以 USB 线很长也不怕干扰。ESP32-S3 自带 USB 2.0 全速（12 Mbps）控制器，两根线直接接到它的 IO20、IO19。

危险来自静电。冬天手指碰一下接口，可能带着几千伏电压，虽然只持续几十纳秒，也足够把 ESP32 的引脚击穿。U5（USBLC6-2SC6）就是挡在中间的保镖：里面是几颗二极管和一个稳压管，信号在 0–5V 之间时它什么都不做；一旦电压冲出这个范围，二极管立刻导通，把电流引到地。

2.4剩下的两件小事

SBU1、SBU2 不接。这两个脚是给视频输出这类“附加功能”用的，原理图里画了叉号。

R17、R18 检测 USB 有没有插。两颗 100kΩ 把 VBUS 一分为二：5V 进来，USB_DET 就是 2.5V，低于 ESP32 能承受的 3.3V。ESP32 的 IO9 读到 2.5V 就知道插着 USB，程序可以据此决定充电时不让电机转。两颗电阻加起来 200kΩ，只吃 25µA，可以一直挂着。

2.5自测

R1、R2 都漏焊了，用 C 对 C 线插手机充电头会怎样？换成 A 转 C 的线呢？

C 对 C：充电头一直看到 CC 是 5V，认为没插东西，不出电，板子完全没反应。A 转 C：线里自带 56kΩ，A 口本来就一直有 5V，所以照样能用。

原理图里 D+ 为什么写着“A6,B6”两个脚？

插头只有一组 D+ / D−。正插时它碰到 A6、A7，反插时碰到 B6、B7。把 A6、B6 连在一起，正反插 ESP32 都能收到数据。

插着 USB 时，USB_DET 是多少伏？为什么不直接把 VBUS 接到 IO9？

5V × 100k ÷ (100k + 100k) = 2.5V。VBUS 是 5V，超过 ESP32 引脚最高 3.3V，直接接会烧引脚，所以先分压。

3

锂电池充电：先恒流，再恒压

学完能说清：锂电池为什么要分两段充、2kΩ 怎么定下充电电流、两颗灯什么时候亮。对应原理图 A 区右半边：U4、R3、C1、C2、LED1、LED2。

3.1锂电池的脾气

电压就是电量

单节锂电池充满是 4.2V，用到一半约 3.7V，到 3.0V 就该充了。程序看电池电压，就能估计还剩多少电。

绝不能超过 4.2V

超过 4.2V 继续充，电池会发热、鼓包，严重时起火。所以充电芯片要把电压精确卡在 4.2V，TP4056 的误差在 1% 以内。

也不能放得太空

放到 2.5V 以下会伤电池。这件事交给电池自带的保护板去管，所以要买“带保护板”的 1S 电池。

3.2看一次完整的充电过程

TP4056 把充电分成几段，自己自动切换：

恒流：电池还没满时，用固定的电流（这块板是约 0.55A）往里灌。电压随着电量慢慢升高。

恒压：电压一到 4.2V，芯片改成死守 4.2V。电池越来越满，能灌进去的电流就越来越小。

结束：电流降到设定值的十分之一左右，芯片判定充满，停止充电。之后电池电压掉到约 4.05V，它会自动再补一次。电池特别空（低于 2.9V）时，开头还会先用小电流“涓流”预充一会儿。

3.4一颗电阻定下充电电流

PROG 脚内部稳在 1V。电阻 R3 接在 PROG 和地之间，流过它的电流就是 1V ÷ R3，芯片再把这个小电流放大 1100 倍，作为充电电流。所以：

充电电流 ≈ 1100 ÷ R3（Ω）A → 1100 ÷ 2000 = 0.55A

不同厂家的 TP4056 这个倍数在 1100 到 1200 之间，所以 2kΩ 实际在 0.55–0.6A。拖一下看看换电阻会怎样：

发热怎么算：TP4056 是“线性”充电芯片，5V 和电池电压之间的差，全部在芯片里变成热。电池 3.0V、电流 0.55A 时，就是 (5 − 3.0) × 0.55 ≈ 1.1W，摸上去会烫手。芯片过热时会自己降电流保护，充得慢一点但不会坏。这也是 PCB 上给它的散热焊盘打了过孔的原因。

3.5两颗灯：开漏输出

CHRG 和 STDBY 叫开漏输出。芯片里面各有一个只能“接到地”的开关（一颗 N-MOS 管）：开关合上，引脚被拉到 0V；开关断开，引脚就悬空，既不输出高电平也不输出低电平。

所以 LED 的电不是芯片给的，是外面的 VBUS 经 1kΩ 电阻供的。开关一合上，电流走 VBUS → R4 → LED1 → CHRG 脚 → 芯片里的开关 → 地，灯就亮了。电流约 (5 − 2.0 − 0.3) ÷ 1kΩ ≈ 3mA，够亮又不费电。上面的充电动画里，右侧小图就是这两个开关随充电阶段开合。

STM32 的 GPIO 设成“开漏输出”就是这个结构。好处是外面接的电源可以和芯片自己的电压不一样，比如这里芯片可以用 5V 点灯，也可以接 3.3V 的单片机去读。

3.6一边充电一边开船，行不行？

TP4056 是靠“流进电池的电流降到十分之一”来判断充满的。如果充电时电机也从电池取电，芯片送出去的电流一部分被电机拿走，它测到的电流永远降不到“充满”的门槛，芯片就永远不停，电池会被长时间挂在 4.2V 上，对寿命不好。

QB12 的做法是：插着 USB 时，全板改用 USB 经 D1 供电，Q1 同时把电池和负载隔开，电池只跟 TP4056 打交道。这个“自动切换”就是第 5 课的内容。

3.7自测

想把充电电流降到 0.3A，R3 换成多大？

1100 ÷ 0.3 ≈ 3.7kΩ。选最接近的标准值 3.6kΩ 或 3.9kΩ，分别约 0.31A、0.28A。

红灯 LED1 亮。这时 CHRG 内部开关合上，脚被拉到接近 0V；STDBY 内部开关断开，绿灯不亮。

没插 USB 时，两颗灯为什么都不亮，也不耗电池？

两颗灯的电来自 VBUS，没插 USB 时 VBUS 是 0V，回路里没有电源，自然不亮。TP4056 在没有 VCC 时会把 BAT 脚断开，从电池吸走的电流只有几微安。

MOS 管当开关：小拨动开关管住大电流

学完能说清：P-MOS 什么时候导通、为什么 SW1 只碰 Q2 的栅极、Q2 断开后电池为什么一点都不漏。对应原理图 B 区：SW1、R14、Q2。

4.1为什么不让开关直接断电池

最简单的电源开关，是把拨动开关直接串在电池正极上。可我们用的 SW1（MSK12C02）是个指甲盖大小的拨动开关，数据手册写着额定 12V、50mA。两个电机起步要 2A，是它额定值的 40 倍，触点很快会烧蚀、粘死。

换一个大开关当然可以，但又大又贵，放不进船舱。更好的办法是让小开关只去“发号施令”，真正的大电流交给一个电子开关去通断。这个电子开关就是 MOS 管。

4.2MOS 管的原理：用电压开关一扇门

MOS 管有三个脚：源极 S、漏极 D、栅极 G。S 和 D 之间是一条可以打开或关上的通道，大电流从这里过；G 是控制端。

关键在于栅极和通道之间隔着一层极薄的绝缘层，栅极本身几乎不吃电流，它靠的是电压：栅极和源极之间的电压差（叫 Vgs）把通道“吸”开。这一点和 STM32 的引脚驱动三极管不一样，三极管要持续往基极灌电流，MOS 管只要电压就够了。

MOS 管分 N 型和 P 型，方向相反：N-MOS 要栅极比源极高才导通；P-MOS 要栅极比源极低才导通，所以它的 Vgs 是负的。QB12 的 Q1、Q2 都是 P-MOS（AO3401A），它的数据手册说：Vgs 低于约 −0.9V 开始导通，到 −2.5V 时导通电阻已经小于 85mΩ，基本就是一根导线了。

4.4关机后电池为什么一点不漏

回想 4.2 的体二极管：它从 D 指向 S。Q2 的 S 接电池、D 接负载，所以体二极管的方向是从负载指向电池。电池想往外放电，得从 S 流到 D，正好是二极管挡住的方向。关断的 Q2 加上它的体二极管，把电池的出路堵死了。

那反方向呢？插着 USB 时 VSYS 有 4.6V，会不会顺着体二极管倒灌进电池？这一路还要先经过 Q1，而 Q1 是“倒着装”的，它的体二极管方向正好相反。两颗管子背靠背，一颗挡一个方向。第 5 课专门讲 Q1。

4.5自测

把 SW1 直接串到电池正极上当总开关，会出什么问题？

SW1 额定 50mA，电机起步电流约 2A，是额定值的 40 倍。触点会发热、拉弧，用不了多久就烧坏或粘死。

开机状态下，SW1 上流过多少电流？电池 4.2V 满电时呢？

电流只经过 R14：4.0V ÷ 100kΩ = 40µA；满电 4.2V 时 42µA。

如果把 R14 拿掉，SW1 拨到 OFF 时会怎样？

栅极就悬空了，电压不确定，Q2 可能半开半关，既关不干净，又可能发热。上拉电阻的作用就是让“没人管”的时候栅极有一个确定的电压。STM32 的输入脚要配上拉或下拉，也是同一个道理。

5

USB 与电池自动切换：两路电源怎么让路

学完能说清：插拔 USB 时板子为什么不会断电重启、电池为什么不会被 USB 直接灌电、Q1 为什么要“倒着装”。对应原理图 B 区下面一行：Q1、R13、D1。

5.1要解决的问题

VSYS 有两个可能的来源：USB 的 5V 和电池。我们希望：

插着 USB：全板用 USB 的电，电池只交给 TP4056 慢慢充，不参与供电（第 3 课 3.6 讲过原因）。

拔掉 USB：电池立刻接手，中间不能断电，否则 ESP32 会重启、手柄会掉线。

任何时候：电不能倒着流。电池不能往 USB 口倒灌，USB 也不能绕过 TP4056 直接往电池里灌。

做到这些只用了三个元件：一颗肖特基二极管 D1、一颗 P-MOS 管 Q1、一颗电阻 R13。

5.2三个元件各管一件事

D1：USB 这一路的单向阀

VBUS 经 D1 到 VSYS。电流只能从 USB 流向 VSYS；用电池时 VBUS 是 0V，D1 反向截止，电池的电不会倒流到 USB 口。

Q1：电池这一路的开关

Q1 的栅极接在 VBUS 上。有 USB 时栅极是 5V，比源极（VSYS）还高，Q1 关断；没 USB 时栅极变成 0V，Q1 完全导通。等于“有 USB 就自动断开电池”。

R13：拔掉 USB 后把栅极拉到地

拔掉 USB 后 VBUS 那根线就悬空了，R13（10kΩ）把它拉到 0V，Q1 才能可靠导通。顺带也让 VBUS 上残留的电很快放掉。

5.4拔掉 USB 的那一瞬间

时序图里能看到三个阶段，这是整节课最精彩的地方：

① D1 还在供电：VBUS 开始往下掉，VSYS 跟着掉，始终比 VBUS 低一个二极管压降（约 0.4V）。

② 体二极管先顶上：VSYS 掉到比电池低 0.5V 左右时，Q1 的体二极管自动导通（方向正好是电池 → VSYS），把 VSYS 托住。这时 Q1 的栅极还没降下来，管子本身还没开，是这颗“天生的二极管”在临时供电。

③ Q1 完全导通：VBUS 继续降，栅极比源极低过了阈值，Q1 打开，导通电阻只有几十毫欧，VSYS 回到几乎等于电池电压。

整个过程 VSYS 最低也只比电池低半伏，ESP32 那边有稳压芯片和电容兜着，完全感觉不到。插上 USB 时反过来走一遍，同样不断电。

5.5Q1 为什么要倒着装

第 4 课的 Q2，源极 S 接电池，这是 P-MOS 最常见的接法。Q1 却是反过来的：漏极 D 接电池这边（BAT_SW），源极 S 接 VSYS。原因全在体二极管的方向上。

接法体二极管方向插着 USB 时会怎样
QB12 的接法：D 接电池，S 接 VSYS电池 → VSYSVSYS（4.6V）比电池高，二极管反向截止，USB 的电进不了电池。拔掉 USB 时它又能先导通顶上，正好两头都占便宜。
反过来：S 接电池，D 接 VSYSVSYS → 电池USB 的 4.6V 会顺着体二极管直接灌进电池，完全绕过 TP4056，没有恒流、没有 4.2V 截止，电池会被过充。
Q2 和 Q1 背靠背：Q2 的体二极管指向电池，Q1 的体二极管指向 VSYS，方向相反。所以只要两颗都关断，无论哪边电压高，电流都过不去。关机时电池彻底隔离，靠的就是这一对。

5.6为什么 D1 用肖特基二极管

普通硅二极管导通时压降约 0.7–1V，肖特基二极管只有 0.3–0.45V。SS34 是 3A 的肖特基管，压降低有两个好处：

发热少：1A 电流时，SS34 发热约 0.4W，普通二极管要 0.7–1W。

VSYS 留得够高：插着 USB 时 VSYS 约 4.6V，比满电电池的 4.2V 还高 0.4V，Q1 的体二极管稳稳反偏，电池保持隔离。压降太大的话，VSYS 可能接近甚至低于电池电压，电池就会偷偷参与供电，TP4056 判断不出充满。

5.7自测

插着 USB 时，Q1 的栅极和源极各是多少伏？为什么它是关断的？

栅极接 VBUS = 5V，源极接 VSYS ≈ 4.6V，Vgs = +0.4V。P-MOS 要 Vgs 为负（约 −0.9V 以下）才导通，正的 Vgs 只会让它关得更死。

把 R13 漏焊了，会出什么问题？

拔掉 USB 后，VBUS 那根线悬空，上面还挂着 C1 等电容，电压慢慢漏，Q1 栅极迟迟降不下来，可能停在“半开”状态发热，VSYS 一直靠体二极管供电，比电池低 0.5V。R13 保证栅极被干脆地拉到 0V。

电源开关拨在 OFF，插上 USB，板子会亮吗？电池会充电吗？

都会。USB 经 D1 直接给 VSYS 供电，不经过 Q2，所以板子照常工作（方便烧录）；TP4056 的 BAT 脚直接接在电池上，也不经过 Q2，所以照样充电。SW1 只管电池往外供电这一路。

3.3V 稳压与去耦：给 ESP32 一口稳定的电

学完能说清：LDO 怎么把变来变去的 VSYS 稳成 3.3V、电池低到多少它就撑不住、ESP32 旁边为什么要并一大一小两颗电容。对应原理图 B 区右上：U3、C3、C4，以及 C 区的 C5、C6。

6.1LDO 的原理：一个自动拧的水龙头

ESP32 要的电压是 3.0–3.6V，VSYS 却在 3.0V 到 4.6V 之间变来变去。U3（AP2112K）是一颗 LDO 线性稳压器，作用是不管输入怎么变，输出都稳在 3.3V。

它里面有三样东西：一个可以调节通断程度的管子（相当于水龙头），一个精准的基准电压，一个放大器。放大器不停地比较输出电压和基准：输出高了就把龙头拧小，低了就拧大，一秒钟调整上百万次。

代价是：输入和输出之间多出来的电压，全部在这个“龙头”上变成热。发热 = (输入电压 − 3.3V) × 电流。所以它叫“线性”稳压，效率等于 3.3 ÷ 输入电压。

6.2最小压差：电池低了为什么撑不住

龙头开到最大也有一点电阻，所以输入至少要比 3.3V 高一点点，这个差值叫最小压差（dropout）。AP2112K 的数据手册（3.3V 版）写着：300mA 时 125mV，600mA 时 250mV（典型值）。也就是说电池 3.45V 以上、电流不超过 300mA 时，3V3 都能稳住。

电池再低，LDO 就“放弃治疗”，输出等于输入减去压差，一路跟着往下掉。掉到 3.0V 以下，ESP32 就会欠压重启。所以程序里要盯着电池电压：低于 3.6V 先让电机减速并闪灯提醒，低于 3.3V 就停船（要回升到 3.5V 才放开，免得电机一停电池回弹、反复启停）。上面的滑块拖到 3.15V、电流调到 300mA 就能看到这个情况。

6.3去耦电容：ESP32 脚边的小水箱

ESP32 的用电不是平平稳稳的。蓝牙每次发射，电流会在几微秒内从几十毫安跳到两三百毫安。LDO 调节需要时间，PCB 走线本身又有一点电感，电流突然变大时，电跟不上，ESP32 脚上的电压就会往下一沉。

解决办法是在 ESP32 电源脚旁边放电容，就像在水龙头边上放一个小水箱：用水突然变多时，先从水箱里取，等主水管反应过来再把水箱补满。这块板放了两颗：

C6 100nF：个头小、内部电感小，反应最快，专门对付纳秒级的尖刺。C5 10µF：存的电多，对付持续几微秒到几十微秒的大口用电。一大一小搭配，从快到慢都照顾到。STM32 每个 VDD 脚边那颗 100nF 也是这个道理。

LDO 两边也各有电容：输入 C3（1µF）、输出 C4（10µF）。AP2112K 的数据手册写着配 1µF 陶瓷电容就能稳定（建议用 X7R 或 X5R）。LDO 内部靠反馈环路调节，输出端电容太小时，环路可能不稳、自己振荡起来。

6.4为什么不用效率更高的开关稳压

DC-DC 开关稳压效率能到 90%，LDO 在 USB 供电时只有 70% 左右。但这里 ESP32 平均只用 0.1A，LDO 多发的热只有 0.1W 量级，电池续航主要被电机吃掉，换 DC-DC 省不了多少电。LDO 外围只要两颗电容，没有电感、没有开关噪声，对蓝牙射频更友好，小板子上它是更省心的选择。

AP2112K 的静态电流只有 55µA（自己维持工作用的电），长时间开机也几乎不耗电，这也是选它的原因之一。

6.5自测

插着 USB、ESP32 用 100mA 时，U3 发多少热？

(4.6 − 3.3) × 0.1 = 0.13W，SOT-23-5 封装完全没问题。

电池 3.3V 时，3V3 还有 3.3V 吗？

没有了。输入都只有 3.3V，再减去压差，300mA 时大约只剩 3.18V。ESP32 还能工作（下限 3.0V），但已经没有余量，蓝牙一发射就可能掉到 3.0V 以下重启。所以电池到 3.6V 左右就该提醒充电，3.3V 直接停机。

U3 的 EN 脚接在哪？为什么？

接 VSYS。EN 是使能脚，高电平工作。直接接输入，等于只要 VSYS 有电，3.3V 就开着。整板的开关由前面的 Q2 负责，这里不需要再单独控制。

7.1模组里已经装好了什么

用 STM32 做板子时，你要自己放晶振、Flash（有时）、复位电路、下载接口。ESP32-S3-WROOM-1 是一块模组：一块小 PCB 上已经焊好了芯片和它离不开的东西，外面罩了一层金属屏蔽壳，整体再当成一个元件焊到我们的板子上。

2MB PSRAM：额外的内存，型号里的 R2。小船用不上这么多，但不加钱。

40MHz 晶振：时钟源，蓝牙对频率要求很准，所以必须用晶振。

板载天线：模组顶端那段弯弯曲曲的铜线。它下面不能有铜，这就是 PCB 上天线区整片留空的原因。

所以模组外面只需要补四样东西：电源和去耦（第 6 课）、EN 复位、BOOT 启动选择、USB。这四样加起来就叫“最小系统”。

7.2EN：等电源稳了再开机

EN 是 ESP32 的“开机键”：高电平芯片工作，低电平芯片复位。和 STM32 的 NRST 一样，低电平有效的是复位。

数据手册要求：电源先稳定下来，EN 再变高。我们用 R7（10kΩ）从 3V3 上拉、C7（1µF）接地，组成一个 RC 延时：上电时电容是空的，EN 从 0V 开始，通过电阻慢慢充上去。时间常数 τ = R × C = 10kΩ × 1µF = 10ms，大约 14ms 后 EN 越过“高电平”的门槛（约 2.5V），芯片才开始启动，这时 3V3 早就稳了。

复位键 SW3 并在 C7 两端：按下时把 EN 直接短到地，芯片复位；松开后电容重新充电，芯片重新启动。

3V3 电源EN虚线：芯片认为“高电平”的门槛

点“上电”。

为什么电容不大不小是 1µF：太小，延时不够，电源还在爬升芯片就启动了，可能启动失败；太大，开机慢、复位键松开后要等很久。10kΩ + 1µF 是乐鑫推荐的值，同时还能滤掉 EN 线上的小干扰，免得电机一转就误复位。

7.3BOOT：开机那一刻看一眼 IO0

ESP32 在 EN 变高的一瞬间，会去看几个特殊引脚（叫 strapping 引脚）的电平，决定这次怎么启动。最重要的是 IO0：

IO0 是高电平 → 正常运行 Flash 里的程序。IO0 是低电平 → 进入下载模式，等电脑把新程序发过来。

平时 R8（10kΩ）把 IO0 拉高，所以开机就运行程序。按住 SW2（BOOT）会把 IO0 接地。这和 STM32 的 BOOT0 脚是同一个思路，只是电平意义反过来。

开机以后 IO0 就是一个普通引脚，程序可以拿它当按键用。实船固件就是：运行中长按 BOOT 约 1.5 秒，切换手柄模式和手机模式，选择存进 flash，板子重启后生效。

实际烧录时，大多数情况根本不用按键：ESP32-S3 的原生 USB 可以让电脑直接把它切进下载模式，点“上传”就行。按键是留给“程序把 USB 搞坏了”的时候用的，比如程序一上来就死循环或进了深度睡眠，电脑连不上它。这时：按住 BOOT → 按一下 RESET → 松开 BOOT，就能强行进下载模式，重新烧一个正常的程序。

7.4原生 USB：一根线下载、打印、调试

STM32 下载程序，要么用 ST-Link，要么经过 CH340 这类 USB 转串口芯片。ESP32-S3 芯片里自带一个 USB 串口 + JTAG 控制器，固定在 IO19（D−）和 IO20（D+）上。插上数据线，电脑上会出现一个串口，能做三件事：

烧录程序；看串口打印（Arduino 里打开 “USB CDC On Boot”，Serial.println() 就从这根线出来）；单步调试（JTAG，进阶用法）。

所以原理图上 USB 这一块，只有 U5 一颗保护芯片，没有任何转换芯片。

7.5用 ADC 量电池：先分压，再读数

电池最高 4.2V，ESP32 引脚最多只能接 3.3V，ADC 能准确测量的范围更是只到 2.9V 左右。所以先用两颗 100kΩ（R11、R12）把电池电压一分为二：4.2V 变 2.1V，3.0V 变 1.5V，正好落在 ADC 的舒服区间。程序读出来再乘 2 就是电池电压。

为什么用 100kΩ 这么大的电阻？分压电阻一直挂在电池上耗电，100kΩ + 100kΩ 只漏 21µA。代价是阻抗高，ADC 采样时会“吸”一口电，电压瞬间被拉低读不准。所以在 ADC 脚上并了 C8（100nF）：采样时从电容里取电，电容再由电阻慢慢补满。

8.1为什么不能用 GPIO 直接带电机

    

      
STM32 课上你可能用 GPIO 点过 LED，几毫安就够了。电机不一样：

      
电流大得多：船上的小电机正常运转要几百毫安，刚启动时能到 2A 以上。ESP32 一个引脚最多给几十毫安，差了两个数量级。

      
要能反转：直流电机的转向由电流方向决定。想倒车，就得把电机两端的正负对调。一个三极管或 MOS 管只能“通 / 断”，做不到对调。

      
电机是个电感：线圈里的电流不能突变，一断电，线圈会产生很高的反向电压，直接接 GPIO 会把芯片打坏。

      
解决这三件事的标准电路叫 H 桥。STM32 课上常见的 L298N、TB6612 模块，里面装的也是 H 桥。我们用的 DRV8833 是同类芯片，体积小，适合 3–10V 的小电机。

8.4PWM 调速，以及两种“衰减”

    

      
电机的转速主要由它两端的平均电压决定。让开关以每秒 2 万次（20kHz）的速度快速通断，接通的时间占一半，电机感受到的就相当于一半的电压。接通时间所占的比例叫占空比。选 20kHz 是因为它刚好超出人耳范围，频率低了电机会发出刺耳的啸叫。

      
问题出在“断开”的那一段：线圈里的电流不能突变，必须找条路继续流，这叫续流。DRV8833 给了两种续流方式：

      
快衰减（IN1 = PWM，IN2 = 0）：断开时四个管全关，电流只能经过 MOS 管自带的体二极管冲回电源。电机两端被反向加上约 −VM（再加上两个体二极管的压降，约 −5V），电流很快掉到零。

      
慢衰减（IN1 = 1，IN2 = PWM）：断开时两个下管同时导通，电机两端被短接（就是“刹车”状态），电流在短路里慢慢减小，一直延续到下一次接通。

8.5限流：R15、R16 这两颗 0.2Ω 电阻

    

      
电机刚启动或被水草缠住时，转子不转，没有反电动势来“顶”着，电流只受线圈电阻限制：3.7V ÷ 1.6Ω ≈ 2.3A。两个电机一起起步就是近 5A。后果有三个：

      
电池电压被拉低：电池和线路都有电阻，大电流一拉，VSYS 往下掉，3.3V 稳压可能撑不住，ESP32 重启、手柄掉线（第 6 课）。触发过流保护：DRV8833 内部的过流保护最低 2A 就可能动作，一动作就关断 1.35ms 再重试，电机一顿一顿的。发热：电机、电池、芯片都在白白发热。

      
DRV8833 自带电流斩波：电机电流从 AISEN 脚经 R15 流到地，在 R15 上产生 I × R 的电压。芯片拿它和内部的 200mV 比较，一超过就切到慢衰减，等下一个内部 50kHz 周期（每 20µs）再接通。于是电流被限制在：

      
I限 = 0.2V ÷ R15 = 0.2V ÷ 0.2Ω = 1A

8.8自测

    

      
AIN1 = 1、AIN2 = 1 时，左电机是什么状态？
刹车。两个下管同时导通，电机两端被短接，电机靠惯性发出的电在短路里消耗掉，很快停下。

      
用慢衰减想让电机正转 30%，IO4、IO5 怎么给？
IO4（AIN1）一直输出高电平，IO5（AIN2）输出 PWM，占空比 70%。IN2 为低的 30% 时间在推电机，为高的 70% 时间在刹车续流。

      
把 R15 换成 0.1Ω，会怎样？

程序里忘了把 IO15 拉高，会怎样？
R9 把 nSLEEP 拉在低电平，DRV8833 一直在睡觉，H 桥全关。不管 IO4–IO7 怎么给，电机都不转。

9.2差速转向：没有舵，怎么拐弯

    

      
QB12 是双体船，左右两个船体各有一个电机和螺旋桨，没有舵。转弯全靠两边转速不同：左边推得比右边猛，船头就往右偏，像坦克、扫地机器人一样。这叫差速转向。

      
把摇杆的前后（y）和左右（x）变成左右两个电机的转速，只要两行：

      
左 L = y + x　　右 R = y − x　　（超过 ±1 的截到 ±1）

      
摇杆往前推：x = 0，L = R = y，直线前进。往右前方推：L 变大、R 变小，右转。只往右推：L = +x、R = −x，一边正转一边反转，原地打转。摇杆回中时总会有一点点偏差，所以给 x、y 各留 8% 的死区，小于它就当 0。

9.3程序

    

      
下面是一份完整、能直接用的程序，用 Arduino IDE 写。手柄通信交给开源库 Bluepad32，它把 Xbox 手柄的蓝牙协议都处理好了，我们只管读摇杆。实船用右摇杆：前后是油门，左右是转向，一只手就能开（程序里是 axisRX() 和 axisRY()）。准备工作：

      
1. 在 Arduino IDE 的开发板管理器里装 esp32_bluepad32 开发板包（添加方法见 Bluepad32 文档），开发板选它下面的 ESP32S3 Dev Module，USB CDC On Boot 选 Enabled。2. 手柄用 Xbox 无线手柄，固件更新到支持蓝牙低功耗（BLE）的版本（Series 款出厂就支持；老的 One 款用电脑上的 Xbox 配件 App 升级）。ESP32-S3 只有 BLE，没有经典蓝牙。3. 烧录后按住手柄顶部的配对键，直到 Xbox 键快闪，几秒内就会连上。

    

    

      

      

    

    

      
对照前面几课看这份程序：drive() 就是 8.4 的慢衰减，那句 (1 − |s|) × 1023 把“想要的速度”换成 IN2 的占空比；ledcSetup(通道, 20000, 10) 设好 20kHz、10 位的 PWM，ledcAttachPin(引脚, 通道) 再把引脚挂到通道上（这是板包 2.x 内核的写法，ledcWrite 写的是通道号，不是引脚号）；digitalWrite(NSLEEP, HIGH) 唤醒 DRV8833；读电池电压和第 7 课一样，再加了一个慢慢跟随的滤波，免得电机一加速电压一掉就误判低电量。电量分三档：低于 3.6V 限速到三成并让 LED3 快闪，低于 3.3V 直接停机保护电池，停机后要回升到 3.5V 才放开（电机一停电池电压会回弹一点，如果 3.3V 就放开，会反复启停）。

      
最重要的一条安全规则藏在 x = 0, y = 0 那行：手柄断开时，摇杆值保持 0，船自己停下。遥控的东西都必须有这种“失控保护”，不然信号一断船就一直往前冲。

    

    
实船固件还多了什么：上面是能跑起来的最小版本。放在交付物里的实船固件（QB12_firmware）在它的基础上又加了这些，下水前后都用得上：
      
    
        
  • 插着 USB，电机禁用：USB 口和走线扛不住电机电流，所以 VBUS 高于 4.2V 就算插着 USB，电机一律不转，低于 3.8V 才算拔掉。
    • 
        
  • 转向量 0.6：右摇杆左右的值先乘 0.6 再混控，转弯不会太猛。缓加速：油门每秒最多变 3.0（满油门 = 1），电池电压不会一下掉很多；松杆则立刻停。
    • 
        
  • 电机方向开关：右电机实测前进时转向是反的，程序里 REVERSE_RIGHT = true 一行就改过来，不用拆线。
    • 
        
  • 直线修正：下水后船前进会往一边偏，按手柄 LB / RB 每次修 1%，两个一起按住 1 秒归零，数值存在 flash 里。
    • 
        
  • 手机 Wi‑Fi 模式：船自己开热点 QB12-XXXX（XXXX 是板子地址的后 4 位），手机连上后浏览器打开 192.168.4.1，屏幕上一个摇杆就能开。运行中长按 BOOT 键 1.5 秒在手柄和手机两种模式间切换。
    • 
        
  • 信号弱就震动：手柄信号低于 -85 dBm 时，手柄每 2 秒震一下，提醒往回开。下水实测不到 10 米就断过连，别开太远。

9.5全课回顾

    

      第 0 课
全景
四根电源线：VBUS、BAT+、VSYS、3V3。每个元件都挂在其中一根上。

      第 1 课
读图规则
名字相同的网络标号就是连在一起的，不用画线。

      第 2 课
USB-C
CC 脚各接 5.1kΩ 到地，充电头看到了才肯给 5V。

      第 3 课
充电
TP4056 先恒流约 0.55A，到 4.2V 改恒压，R3 定电流。

      第 4 课
MOS 管当开关
小拨动开关只管 Q2 的栅极，大电流走 Q2。

      第 5 课
自动切换
有 USB 走 D1，没 USB 走 Q1，中间不断电，电流不倒流。

      第 6 课
稳压与去耦
LDO 把 VSYS 降到 3.3V，10µF + 100nF 就近补电流。

      第 7 课
最小系统
EN 延时开机、IO0 选启动方式、分压后用 ADC 量电池。

      第 8 课
H 桥
IN1、IN2 四种组合；PWM 慢衰减调速；0.2Ω 限流 1A。

      第 9 课
串起来
摇杆 → 蓝牙 → 换算 → 混控 → PWM → H 桥 → 电机，断线自动停。
