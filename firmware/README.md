# QB12 固件

`qb12_boat/qb12_boat.ino`：ESP32-S3 + Bluepad32，接 Xbox Series 手柄（型号 1914，固件要 v5.15 以上，BLE）。
基线来自 `courses/circuit/l9.js`，加了电机反向开关、蓝牙断开停机（不按“多久没数据”判失联：Xbox 摇杆不动就不发数据，原来的 500 ms 超时在满油门时会误停，11-05 已去掉）、缓加速、低电压限速、插 USB 禁电机。
真板：11-03 烧录运行，11-05 桌上（无桨）验证过电池、充电、推满不断、关手柄 1 s 停、电机四向（当时是分离式操控）；11-11 下水一次（见下）。操控 11-11 起改成单摇杆，单摇杆版、手机模式、模式切换、直线修正都只验证过编译，没在真船上实测。

## 编译（环境装在这个目录，不装到全局；全局只有 arduino-cli 这个程序）
```bash
cd firmware && ./build.sh
```
Bluepad32 的 Arduino 板包来自 https://github.com/ricardoquesada/esp32-arduino-lib-builder 的 index。数据放在 `firmware/.arduino/`（已 gitignore）。

### Apple Silicon（没装 Rosetta）的两处改动
Arduino 板包里有两个只有 x86 版本的小工具，没有 Rosetta 跑不了，`build.sh` 第一次运行后要手动换（在 `.arduino/` 里，不影响系统）：
- `esptool`：换成调用 `.venv` 里 pip 装的 esptool 4.8.1 的脚本（`requirements.txt` 里有）；原文件改名 `esptool.x86`。
- `ctags`：换成输出为空的脚本（等于不自动生成函数原型，`.ino` 里函数都已先定义后使用）；原文件改名 `ctags.x86`。
重新下载 `.arduino/` 后这两处要再做一次。装了 Rosetta 就不用换。

### 和第 9 课代码的区别
第 9 课 `courses/circuit/l9.js` 的代码用了 Arduino-ESP32 3.x 的 `ledcAttach(引脚, …)`，但 `esp32_bluepad32` 4.1.0 板包是 2.0.x 内核，编译会报 `ledcAttach was not declared`。这里改成 2.x 的 `ledcSetup/ledcAttachPin/ledcWrite(通道)`。课程第 9 课（`courses/circuit/l9.js`）已同步成 2.x 写法。

## 烧录和上板
```bash
./build.sh upload /dev/cu.usbmodemXXXX     # 板子 USB-C 接电脑，先看 ls /dev/cu.usb*
```
1. 先架空船（桨离水），只接 USB，不接电机，看串口和 LED：没连手柄慢闪。
2. 手柄：按 Xbox 键开机，再按住顶部配对键 3 秒松开，等 LED 常亮。
3. 拔掉 USB（插着 USB 电机禁用），只用电池，接电机 J3/J4，推右摇杆（只用右摇杆：前后油门、左右转向，转向量 `TURN_GAIN` 0.6）。转向不对就改 `REVERSE_LEFT/RIGHT` 或对调电机线。
4. 手柄关机，电机立刻停（蓝牙断开后目标速度归零；11-05 实测关手柄 1 s 内串口显示未连）。出信号范围后蓝牙多久超时断开，未实测。

## 两种遥控模式（11-11）
- **手柄模式**（默认）：Xbox 手柄蓝牙。信号弱于 `RSSI_WARN`（-85 dBm）时手柄每 2 秒震一下，提醒往回开。11-11 实测下水不到 10 m 就断。
- **手机模式**：船开 Wi‑Fi 热点 `QB12-XXXX`（后 4 位是 MAC 地址），密码 `qb12boat`。手机连上后，浏览器打开 `http://192.168.4.1`：屏幕上一个摇杆，手指按哪里哪里就是中心，上下是油门、左右是转向，松手就停。超过 0.5 秒没收到手机指令，船就停；切走网页或锁屏也会停。网页上显示电量（按 1S 锂电电压换算，电机转时偏低）、电压、船收到的手机信号、ESP32 芯片温度、左右电机输出（没有测速，是 PWM 输出百分比，蓝色前进、橙色后退）；信号低于 -78 dBm 会提示往回开。距离还没实测。
- **切换**：长按板上 BOOT 键（SW2）1.5 秒，LED 快闪后重启，选中的模式存在 flash 里。开机时 LED 闪 1 下是手柄模式，闪 2 下是手机模式。
- 两种模式的发射功率都开到最大档：蓝牙 +21 dBm 档，Wi‑Fi 19.5 dBm。串口每秒输出一行状态，行首 `[手柄]` 或 `[手机]`。

## 直线修正（11-11）
前进时船往一边偏（两个电机或桨不完全一样）：
- 往左偏：按手柄 **RB**，或点网页右下角的 ▶；往右偏：按 **LB**，或点 ◀。每次 1%，手柄会轻震一下。
- LB 和 RB 一起按住 1 秒归零（手柄长震），或在网页上长按中间的数字 1 秒。
- 往右修是压低右电机，往左修是压低左电机，最多 30%。停手 2 秒后存进 flash，关机不丢。串口和网页都会显示当前值。
- 要修到 15% 以上，多半是机械问题：桨装反、两边桨型号不一样、轴发卡，或者有一边进水变重。
