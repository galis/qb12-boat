# 踩过的坑（不要再踩）

按领域分组，每条写「现象 → 原因/做法」，括号里是发现日期。新坑当场追加到对应小节；过时的删掉。
开工前先看相关小节。环境搭建细节在 `docs/开发环境.md`。

## 固件（ESP32-S3 / Arduino CLI / Bluepad32）
- Bluepad32 板包是 arduino-esp32 2.0.x 核心：用 `ledcSetup/ledcAttachPin`，`ledcAttach` 不存在（10-22）。课程 `l9.js` 里的代码曾经写错。
- 本机没有 Rosetta，板包自带的 x86 esptool/ctags 跑不了，已用包装脚本替换，见 `firmware/README.md`（10-22）。
- `ARDUINO_DIRECTORY_*` 会装到全局，要用 `ARDUINO_DIRECTORIES_DATA/DOWNLOADS/USER`（10-22）。
- 摇杆推到底不动、或回中静止时，Xbox 手柄不发数据 → 不能用"多少毫秒没数据就判失联"，会在满油门时误停；只靠蓝牙断开（`onDisconnected`）停机（11-05）。

## 主控板测量（Rev A）
- 只接电池时 VBUS 有约 2 V：ESP32 运行时 D+ 上拉经 USBLC6 内部二极管倒灌到 VBUS，约 0.2 mA，无害；按住 RESET 会掉到 0.1 V。固件 VBUS>4.2 V 算插着、<3.8 V（`USB_OFF_V`）算拔了，不会误判（11-05）。
- 不上电测 VBUS/VSYS 对地电阻，数值会慢慢爬（电容充电），读稳了再记；测点要按测点图点准，点到 J2 地脚会读错（11-03）。
- 万用表读出负电压先看表笔：黑表笔插在 mA 孔会读 −3.92 V（11-05）。

## KiCad / PCB / 嘉立创文件
- 跑 DRC 或导出时，`.kicad_pro` 必须和 `.kicad_pcb` 在同一目录，否则按默认网络类（间距 0.2 mm）检查，报几十条假违规。
- KiCad 10 改过的 API：`GetFieldByName` → `GetField`，`Get/SetDoNotAllowCopperPour` → `...ZoneFills`，`GetBoardPolygonOutlines` 多一个参数，`SHAPE_POLY_SET.PM_FAST` 去掉了（10-20）。
- 仓库里的板子、工程包是 KiCad 10 格式，KiCad 8 打不开。
- 嘉立创 Gerber 要用 `export_jlc.sh` 的 `--no-x2 --no-netlist`；曾交付过 X2 格式，重导后几何不变（10-19）。
- 坐标文件选项：「仅 SMD」会漏掉 SW1；「排除通孔」会漏掉 J1/U2/SW1。
- PCB 3D 导出只能用 `pkg/QB12_KiCad/` 里的板子；`out/`、`lib/` 的 3D 路径是旧绝对路径，导出来没有元件。
- 改元件要同步所有副本：U3 换成 AP2112K 后，课程、视频 ep06、`pkg/QB12_KiCad`、`QB12_KiCad工程.zip` 里还留着 ME6211；LCSC Part 字段也曾只改了一处（10-19、10-23）。
- `extract.py` 导出图层时丢了 SVG 根上的 `stroke-linecap/linejoin: round`，阻焊/丝印线头变方；在课程 viewer 的 CSS 里统一补（10-19）。

## 船体 / 3D 打印
- 打印件要查「实体块数=1、封闭、法向」，不能只看渲染图：舱罩裙边一直是单独一块，复核几轮都没发现，嘉立创审核才报。`export_print` 已自动检查（10-28）。
- 嘉立创审核报"法向错误"可能是误报（trimesh 查 0 翻转），可选官方人工处理（10-28）。
- 半透明渲染要用 FrontSide，否则透出内壁颜色（10-21）。
- 改船体后必须重跑 `check_pcb_fit.py` 再出 STL/USDZ；舱口加长会让盖板抽出时撞到 x=178 的舱罩挂钩（10-27）。
- 电机按实物卡尺量（铁壳 Ø17.18 × 22.79，接线片 3.58），不要用官网尺寸（10-27）。

## 浏览器 / 网站操作
- 浏览器分工见全局 `~/.claude/CLAUDE.md`：默认内置；嘉立创、立创商城、淘宝、微信、飞书一律 Chrome（10-28）。
- 内置浏览器传不了本地文件到嘉立创，下单用 Chrome 的 `file_upload`（10-22）。
- 内置浏览器会拦截 `window.open`：嘉立创「立即下单」、SMT「下一步，BOM匹配选型」都要开新窗口，用户亲手点也进不去（10-23）。
- 淘宝等网站每秒最多操作 1 次，批量点会触发验证码；勾选状态离开页面就丢（10-23）。
- Chrome 扩展在淘宝聊天页每步都要点 Allow，改权限模式、加 hook 都没用；操作前提醒用户在电脑前（10-28）。
- 内置浏览器扫码登录：扫完等它自己跳回首页、看到账号再操作，中途换页登录就丢（10-28）。

## 工作方式
- `perl -pi -e` 替换的内容里有中文就报 `Unrecognized character`，那一处没改但脚本照样往下跑 → 含中文的替换用 Python 做，改完 grep 确认（2026-11-26）
- 挪目录后 `git add -A` 一下子多出 1.8 万个文件 → .gitignore 里的规则带着旧前缀（`project/video/...`），新位置没被忽略。挪目录前先改 .gitignore，`git add` 后看一眼 `git status --short | wc -l`（2026-11-26）
- 并行派多个子 Agent 时核对 agent id 和任务的对应关系，曾把 p6 的修改发给了 p8（10-19）。
- 子 Agent 报"已完成"不等于对：交付前自己看一眼结果或 diff。
