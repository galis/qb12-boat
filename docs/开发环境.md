# 开发环境与重跑方法

从 CLAUDE.md 移出来的细节，需要时再读。

## 环境（每个项目一份，不装到全局）
```bash
cd ~/Documents/WorkHome/ai_boat
/opt/homebrew/bin/python3.12 -m venv .venv && source .venv/bin/activate   # 系统自带的 3.9 太旧
pip install -r requirements.txt
python -m playwright install chromium        # 浏览器装在 ~/Library/Caches/ms-playwright，按版本隔离
# 第二个环境：KiCad 10 自带的 Python（3.9，带 pcbnew）+ shapely，给 hardware/pcb 的脚本用
KPY=~/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3
"$KPY" -m venv --system-site-packages .venv-kicad && .venv-kicad/bin/pip install -r requirements-kicad.txt
```
- `.venv/` 和 `.venv-kicad/` 只属于这个仓库，都在 `.gitignore` 里。
- 全局只装应用程序，不装 Python 包：
  - KiCad 10（`~/Applications/KiCad/`）。路径统一写在 `tools/kicad_env.sh`，定义 `$KPY`（优先用 `.venv-kicad`）、`$KCLI`、`$JAVA`；pcb 下的 .sh 脚本都会 source 它。脚本兼容 KiCad 8 和 10，但仓库里的板子、工程包、交付物都已是 KiCad 10 格式（8 打不开）。
  - ffmpeg（`brew install ffmpeg`）。
  - Java：`brew install openjdk@21`（keg-only，不链接到全局，只给 Freerouting 用）。
- 固件：Arduino CLI 的数据放在 `firmware/.arduino/`（用 `ARDUINO_DIRECTORIES_DATA/DOWNLOADS/USER`；`ARDUINO_DIRECTORY_*` 会装到全局）。esptool、ctags 的包装脚本见 `firmware/README.md`。

## KiCad 10 与 8 的差别（2026-10-20 实测）
- 现有板子的 DRC、钻孔、坐标文件和 8.0.9 一致，Gerber 只有铺铜填充的取整差异；从 `build_board.py` 重跑到 `finalize.py`（用现有的 `r3/QB12.ses`），结果和 `out/QB12.kicad_pcb` 逐个对象一致。
- 改过的 API：`GetFieldByName` → `GetField`，`Get/SetDoNotAllowCopperPour` → `...ZoneFills`，`GetBoardPolygonOutlines` 多一个参数，`SHAPE_POLY_SET.PM_FAST` 去掉了。
- 跑 DRC 或导出时，`.kicad_pro` 必须和 `.kicad_pcb` 在同一目录，否则按默认网络类（间距 0.2 mm）检查，报几十条假违规。
- 界面名称、菜单路径变化不少，课程里以 `courses/pcb/facts_kicad10.md` 为准。

## 各子项目怎么重跑
| 子项目 | 位置 | 命令 / 入口 |
|---|---|---|
| PCB | `hardware/pcb/` | `make_all.sh`：netlist.py → build_board.py → route_a/route_b（Freerouting 1.9.0 在 `tools/`）→ finalize.py → `export_jlc.sh`（要带 `--no-x2 --no-netlist`）→ make_bom.py。Freerouting 每次结果不同；只想验证流程，就把现有的 `r3/QB12.ses` 交给 route_b.py |
| 船体 | `hardware/hull/` | `python build_model.py out && python export_assembly.py out`；试件 `make_coupon.py` |
| 装配检查 | `hardware/fitcheck/` | `check_pcb_fit.py`（[9] 是盖板滑动检查）、截面图和渲染图 |
| 渲染页 | `viewer/` | `gen_assembly.py`（在仓库根目录跑）、`gen_viewer.py`、`gen_coupon_viewer.py` |
| 固件 | `firmware/` | `build.sh`（板包 `esp32-bluepad32:esp32@4.1.0`，用 arduino-esp32 2.0.x 的 `ledcSetup/ledcAttachPin` API） |
| PCB 3D USDZ | `tools/pcbusdz/` | 先 `hardware/pcb/make_pkg.sh`，再 `make_pcb3d.sh [输出目录]`：导出 GLB（带 `--subst-models --include-pads`）→ `glb2usdz.py`。只能用 `pkg/QB12_KiCad/` 里的板子，`out/` 和 `lib/` 的 3D 路径是旧绝对路径，导出来没有元件 |
| PCB 顶面贴图 | `hardware/pcb/tex/` | `export_tex.sh`：导出 SVG（铜层 `--drill-shape-opt 1`，其余 0）→ `make_tex.py` 合成 `top_tex.png` |
| 电路课页面 | `courses/circuit/` | `python integrate.py` |
| PCB 课页面 | `courses/pcb/` | `python build.py --strict`；测试 `python tools/test.py`；数据 `$KPY tools/extract.py`。KiCad 截图方法见 `assets/kicad_shots.md`；`tools/kshot/` 是旧的 Linux + Xvfb 脚本 |
